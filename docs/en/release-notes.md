## Unreleased (current branch)

**Platform**

- **.NET 11.** Every library, the SDK, templates, tools and tests target `net11.0` / `net11.0-android` / `net11.0-ios`.
  Needs the .NET 11 SDK. → [Migration guide](migration.md)
- **CoreCLR on Android.** `Xeno.SDK` sets `UseMonoRuntime=false` for Android apps. Set `UseMonoRuntime=true` to go back to Mono.
- **Android API 37** platform and workload required by `net11.0-android`.

**Fixes**

- Android frames are paced on vsync, and lazy lists no longer rewindow per item (smoother scrolling on 120 Hz displays).
- Text is no longer clipped at fractional screen densities; tablet layout fixes.

## 0.1.0-preview.6 — 20 October 2026

**New**

- **Overlays:** `Snackbar`, `Alert`, `Dialog`, `Popup`, `BottomSheet`, with customisable `OverlayAnimation`, swipe to dismiss,
  and anchored popups that follow their anchor.
- **Scaffold top bar:** a fixed application bar above the page (`ITopBarPage`, `TopBars.ForActivePage`), rebuilt per page and
  animated with it.
- **SDK:** implicit imports for `XenoUI.StandardLibrary.Overlays` and `Shell`, a `Dialog` alias on Android;
  `NativeWindowMetrics.SafeAreaTop` for the iOS notch.

**Fixes**

- Navigation: going back is the exact mirror of going forward (the leaving page stays on top); transitions start on their
  first frame; top bars move with their pages; a modal drawer keeps the bottom bar under its scrim; cross-fades keep the
  outgoing page as an opaque backdrop.
- iOS: overlay callbacks run on the UI thread.

## Between preview.4 and preview.6 (October 2026)

- **VS Code extension** with the XenoUI Preview panel and project/page/component creation on macOS, Linux and Windows.
- **iOS media:** an AVPlayer backend with native video under the UI; end of playback handled on the main thread.
- **SDK:** `OutputType` defaults to `Exe` before `Microsoft.NET.Sdk` (fixes an iOS `CS8805`).
- Visual Studio and VS Code preview/templates refinements.

## 0.1.0-preview.4 — 12 October 2026

- **Page previews** attach to their app object without starting it (`[Preview]` on pages).
- **New-free DSL:** `UseState`, `UseStates`, `UseScroll`, `UseLazyList`, `UseTextEdit`, `InputOptions`, `Selection`, `Caret`,
  `Glyph` — declare state without `new`.
- `NativeTunnel.CreatePlayer(MediaKind)` and `Configure(volume, speed, loop)` for media.
- Previews compile and render with the project's own XenoUI runtime.

## 0.1.0-preview.3 — 12 October 2026

- **Templates:** `xenoui` (app), `xenoui-page`, `xenoui-component`.
- **Visual Studio extension** with the XenoUI Preview window and an isolated render server.
- NuGet packaging (`packages/`, `Pack-NuGet.ps1`), documentation for installation and the previewer.

## Earlier previews

The Android and iOS hosts were merged into `XenoUI.Platforms`; the `[Preview]` attribute and the headless preview renderer
were introduced; bidirectional text ordering and an Arabic right-to-left demo were added. See the repository history for
details.

## How to read an entry

| Marker | Meaning |
|---|---|
| **New** | A capability you can start using |
| **Fixes** | A behaviour that changed to match the documented one |
| **→ Migration guide** | You must change something |

Behaviour that is not covered by a test and not described in the documentation is **not** a contract, even if it works
today ([Decisions and V1 trajectory](architecture/decisions-v1.md)).
